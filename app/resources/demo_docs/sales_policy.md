# 销售经营分析口径

## 销售总额

销售总额以订单确认日期作为统计日期，口径为订单确认后未发生整单取消的有效销售额。退款订单按照退款发生月份冲减销售总额，不追溯修改原订单月份。

## 订单数

订单数按有效订单去重统计，一个订单包含多个商品时只计一单。测试订单、内部调拨单和已整单取消订单不计入订单数。

## 商品排名

商品排名默认按销售总额降序。销售总额相同的商品，依次按销售数量降序和商品编号升序排列。未指定排名数量时，默认展示前五名。

## 部门范围

业务人员只能查看本部门销售数据。具有 exec 或 admin 角色的管理人员可以查看全部门汇总。权限范围由服务端身份决定，不接受用户自行指定部门。
